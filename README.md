# HUD Trainer

Private Trainings-PWA im HUD-Stil. Läuft vollständig lokal im Browser: kein Backend, kein Konto, kein Tracking, offline-fähig.

Eigenständige Gestaltung, keine Verbindung zu Marvel oder Disney.

```
npm install
npm run dev     # Entwicklung
npm test        # Unit-Tests
npm run build   # Produktionsbuild
npm run e2e     # Smoke-Test und Screenshots (390 × 844)
```

Deployment: Push auf `main` veröffentlicht über GitHub Actions auf GitHub Pages.
